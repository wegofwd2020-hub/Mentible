# Web fonts fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The deployed web app renders in **Inter** (body) + **Fraunces/Source Serif** (headings) instead of OS system fonts.

**Architecture:** On web, register canonical weight-synthesizing `@font-face` families (`Inter`, `Fraunces`, `Source Serif 4`, `OpenDyslexic`) from the already-imported font-module URIs, and set Inter as the default text font so react-native-web `Text` inherits it and the theme's `fontBody`/`fontHeading` stacks resolve. Native untouched.

**Tech Stack:** React Native Web (Expo); TypeScript; Jest (jsdom for the unit test); a local web build for the render verify.

## Global Constraints

- **Web-only.** `applyGlobalFont`'s native path stays unchanged; new code lives in `.web.ts` (+ a native no-op stub). Do NOT `!important`-clobber explicit families — icon fonts (Ionicons/Material), monospace (code/keys), and explicit Fraunces/Playfair/Source-Serif heading styles MUST still render.
- Mobile `npx tsc --noEmit` + full `npx jest` + `npx eslint .`. Commit ends with `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.
- **Confirmed facts:** `app/_layout.tsx` calls `useFonts(FONT_ASSETS)` + `applyGlobalFont()` at startup. `FONT_ASSETS`/the font modules are in `src/constants/fonts.ts` (`Inter_400Regular`…`Inter_700Bold`, `Fraunces_400Regular/600SemiBold/700Bold` + italics, `SourceSerif4_400Regular/600SemiBold/700Bold`, OpenDyslexic vendored ttf). `theme.fontBody` (web) = `"Inter, system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif"`; `theme.fontHeading` (web) = `"'Source Serif 4', 'Iowan Old Style', Georgia, serif"` (`src/constants/theme.ts:91`). Expo web resolves a font module to a URI via `expo-asset` `Asset.fromModule(mod).uri` (or the module is already a URI string on web). Live-verified bug: body/heading compute to `-apple-system`; `Inter_*` faces `unloaded`.

    Resolve each URI: `Asset.fromModule(Inter_400Regular).uri` (import the modules from `@/constants/fonts` — re-export them there if not already exported, or import directly from `@expo-google-fonts/*` as `fonts.ts` does).
